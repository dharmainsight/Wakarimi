# 原典との対応：遍き収取・励起・現起・不散乱

**用途**：Wakarimiの四つの品質ゲートの背景、下位要素、適用限界を確認する。新規制作・リライトのたびに仏教語を本文へ表示するための資料ではない。

## 0. 出典と解釈の境界

- [『無礙解道』Ps 1.1 Ñāṇakathā, Suta­mayañā­ṇanid­desa（パーリ語）](https://dhammatalks.net/suttacentral/sc2016/sc/pi/ps1.1.html)：道支八つの語義が並ぶ箇所、および尋・伺・喜・楽・心一境性の語義を確認する。原典の `pariggahaṭṭha` は「遍き収取・包摂・把握」等に訳し得るが、「正語＝全知識を完全に理解させること」という意味へ拡大しない。
- [SN 45.8 Maggavibhaṅga Sutta](https://origin.dhammatalks.org/suttas/SN/SN45_8.html)：正語の四禁、四正勤、四念処、四禅などを参照する。
- [MN 10 Satipaṭṭhāna Sutta](https://www.dhammatalks.org/suttas/MN/MN10.html)：身・受・心・法と、法念処に含まれる五蓋・五取蘊・六処・七覚支・四聖諦の観察対象を参照する。

**厳密性**：経典本文での定義／Wakarimi独自の教育設計への類比／読者テストで検証した効果、の三層を混同しない。仏教実践の修行結果や、読者の心に特定の禅支が生起したことを保証しない。

## 1. 八正道の語義から作業上の品質原則へ

| 道支 | Ps 1.1 の語義 | Wakarimiでの設計上の類比 |
|---|---|---|
| 正見 `sammādiṭṭhi` | `dassanaṭṭha` 見る・洞察 | 受け手が把握すべき現象・問い・事実と結論を正確に見定める |
| 正思惟 `sammāsaṅkappa` | `abhiniropanaṭṭha` 向け置く | 何に向けて理解を進めるかを定める |
| 正語 `sammāvācā` | `pariggahaṭṭha` 遍き収取・包摂 | 対象を必要十分に把握し、誤りのない言葉へ翻訳する |
| 正業 `sammākammanta` | `samuṭṭhānaṭṭha` 生起 | 読者が説明を判断・操作・行動に移せる形にする |
| 正命 `sammāājīva` | `vodānaṭṭha` 清浄 | 誤導・過度の誘導を排し、継続利用に耐える成果にする |
| 正精進 `sammāvāyāma` | `paggahaṭṭha` 励起・奮起 | 理解を妨げる要因を予防・解消し、理解の獲得と維持を支える |
| 正念 `sammāsati` | `upaṭṭhānaṭṭha` 現起・現前 | 受け手の注意と理解対象を途中で見失わせない |
| 正定 `sammāsamādhi` | `avikkhepaṭṭha` 不散乱 | 中心の問いを保ち、理解を統合する |

上の表は道支の現代的な言い換えではなく**教材制作への仮説的な類比**である。正見の四聖諦、正思惟の出離・無瞋・不害、正業の不殺生・不偸盗・不邪淫、正命の不邪命といった修行上の実際の定義はSN 45.8に従う。

## 2. 正語：遍き収取と四つの言葉の戒め

**原典上の区別**：Ps 1.1 は正語の `pariggahaṭṭha` を挙げる。一方、SN 45.8が示す正語の実践は、妄語・両舌・悪口・綺語から離れること。片方をもう片方の代わりにしない。

| 下位要素 | コンテンツ上の操作 | 不合格例 |
|---|---|---|
| 不妄語（虚偽を避ける） | 一次情報・引用・数値・限定条件を守り、事実／推論／仮定を区別する | 読みやすさのために事実を創作する |
| 不両舌（分断する発言を避ける） | 読者を分断したり、相手を対立させたりする扇動をしない。前後の説明の矛盾も確認する | 他者を貶めて自説を正当化する |
| 不悪口（粗暴な発言を避ける） | 間違いを指摘するときも行動・論拠を対象に、礼節ある言葉で述べる | 理解できない人を嘲る |
| 不綺語（無益な発言を避ける） | 受け手の目標に関係しない蘊蓄・煽り・繰り返しを省く | 雑談で因果関係を断ち切る |

**遍き収取の検査**：①対象と範囲、②必要な定義、③依存する前提、④仕組み・因果、⑤成立／不成立の条件、⑥反例・例外、⑦別事例への適用、を目標に照らして照合する。これらを毎回すべて説明するのではなく、**理解に不可欠なものを漏らさず、不要なものを付け加えない**。全部網羅することと、目的に対して完全であることは異なる。

## 3. 正精進：四正勤の四操作

SN 45.8の四正勤（未生悪の防止・既生悪の断除・未生善の生起・既生善の維持発展）を、教育設計の修正ループに類比する。

1. **防護（未生の悪を起こさない）**：前提欠落・誤解を生む比喩・未定義語などを先回りして防ぐ。
2. **断除（既生の悪を捨てる）**：発生した誤解を、具体的な反例や因果の比較で解く。誤解に至った読者を責めない。
3. **修習（未生の善を起こす）**：知らないことを問い・具体例・原理・適用につなぎ、自分で答えを再構成する足場を用意する。
4. **護持・増長（既生の善を保つ）**：短い想起・別条件の問題・時間を置いた確認で理解を維持し、広げる。

**品質検査**：「誤解がまだ起きていないか／すでに起きたか」「理解がまだ成立していないか／すでに成立したか」で適切な操作を選ぶ。四正勤は「読者を頑張らせること」の同義語ではない。

## 4. 正念：四念処を観点として活用する

本来の四念処は**身随観・受随観・心随観・法随観**。教材を四章に分ける命令でも、読者の内面が著者に観測できるという主張でもない。

| 観点 | 原典上の観察対象 | 説明設計への限定的な類比 |
|---|---|---|
| 身 | 身体と身体的現象 | 表示、視聴速度、図の見やすさ、操作や視線移動の負荷 |
| 受 | 快・苦・不苦不楽などの受 | わからなさや納得に伴う反応の可能性を考え、誤った刺激で誘導しない |
| 心 | 貪り・瞋り・散乱・集中等を含む心のあり方 | 読者の先入観・迷い・注意の変化を**仮説として**扱う |
| 法 | 教えられる法の範疇（五蓋、五取蘊、六処、七覚支、四聖諦等） | 対象の要素・条件と理解阻害の構造を整理する |

法念処の下位の法カテゴリーを参照するときは、**五蓋＝阻害、五取蘊＝分析対象、六処＝知覚の条件、七覚支＝修習の要因、四聖諦＝問題と解決の構造**を混同しない。コンテンツに必要な観点だけ活用し、科学的な認知診断の確定事実として扱わない。

## 5. 正定：五禅支・五蓋・四禅

Ps 1.1 は道支の語義に続けて、尋・伺・喜・楽・心の一境性に関する語義を挙げる。五禅支は特に**初禅を説明する要素**であり、「五つの連続した学習ステップ」ではない。SN 45.8 の四禅では、第二禅で尋・伺が止み、第三禅で喜が退き、第四禅で楽苦を離れる。教育への類比は禅定そのものとは区別する。

| 五禅支 | Ps 1.1 の語義 | 受け手への設計上の支援 | 反例・検査 |
|---|---|---|---|
| 尋 `vitakka` | `abhiniropanaṭṭha` 対象に向け置く | 中心の問い・観察対象・学習動機を明示する | 読む理由が分からないまま専門語が始まる |
| 伺 `vicāra` | `upavicāraṭṭha` 対象を吟味する | 前提を維持して機構・因果を追わせ、途中で問いを取り替えない | 関連する別話題へ脱線する |
| 喜 `pīti` | `pharaṇaṭṭha` 喜が広がる | 反例の解決・発見・予測の成功が自然にわかるようにする | 驚愕演出だけで理解した気にさせる |
| 楽 `sukha` | `abhisandanaṭṭha` 安楽が行き渡る | 無理のない負荷・明快な結論・安心して問い直せる表現 | 漠然と心地よいだけで内容が曖昧 |
| 一境性 `ekaggatā` | `ekaggaṭṭha` 心が一点にまとまる | 前提・具体例・原理・結論を単一の概念モデルへ統合する | 最後まで読んでも一つの説明に収束しない |

**五蓋（典拠上の妨げ）**：欲貪 `kāmacchanda`、瞋恚 `byāpāda`、惛沈睡眠 `thīnamiddha`、掉挙悪作 `uddhacca-kukkucca`、疑 `vicikicchā`。説明上の*類似の阻害*として、気を散らす刺激、威圧的表現、過剰負荷や退屈、頻繁な文脈切替、解消されない疑問を点検する。ただし五蓋とこれらの文章問題を一対一の同義としない。

**確認可能な代理指標**：中心の問いを再述できる／推論の次を予測できる／反例との違いを説明できる／章を越えて原理を統合できる。これらは理解の行動証拠であって、禅支や情動そのものを計測するものではない。

## 6. 同じ段落にある関連体系（必要時のみ）

Ps 1.1には道支や五禅支と同じ並びに、五根・五力・七覚支への言及もある。これは**四ゲートの直接の下位要素ではない**。深い設計監査が必要な場合の補助軸とする。

- **五根／五力**：信・精進・念・定・慧。信を盲信として扱わず、検証可能な理解の前進と組にする。五力では各々が逆境でも動揺しない強さとして扱われる。
- **七覚支**：念・択法・精進・喜・軽安・定・捨。理解を進める働きと、過剰な刺激を鎮める働きを同時に考える。喜を興奮演出に、捨を無関心に置換しない。
- **四禅**：初禅から第四禅の要素変化を原典のまま保持する。Wakarimiには修行段階の到達判定を持ち込まない。

## 7. 最小チェック（内部のみ）

- **遍き収取**：目的に必要な範囲・前提・成立条件・例外を揃えたか。四つの正語の戒めに反する言葉はないか。
- **励起**：未発・既発の誤解、未獲得・既獲得の理解に対し、予防／訂正／形成／定着を選んだか。
- **現起**：知覚負荷、反応の可能性、注意、対象を見失わせないか。
- **不散乱**：尋で焦点が定まり、伺で維持され、喜・楽に対応する無理のない体験が支えられ、一境性で統合されるか。五蓋に類する障害を増やしていないか。
- **実測との区別**：読者テストなしに「完全に理解された」「禅支が生起した」と断定していないか。
