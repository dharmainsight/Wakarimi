# Wakarimi（ワカリミ）

**情報を並べるより、人が理解できる順序で説明する。**

Wakarimiは、説明文・教材・動画台本・技術文書などの新規作成、改稿、レビューに使うChatGPT向けSkillです。

## 考え方

知識の関連順ではなく、受け手の既有知識から理解の到達点までの依存関係に沿って説明を組み立てます。

> 既有知識 → 疑問 → 新しい概念の必要性 → 具体例 → 仕組み → 一般化 → 理解の確認

これは**推奨される設計の補助線**であり、すべての文章に強制する型ではありません。結論先行の実務文書や熟練者向けリファレンスには用途に合う順序を優先します。

## できること

- **新規制作**：受け手の既有知識・到達目標・概念の依存関係から構成を作る
- **リライト**：正確性と指定内容を保ち、理解を妨げる順序や説明を修正する
- **レビュー**：前提の欠落、概念の飛躍、不要な寄り道、説明しただけで理解済みと見なす箇所を特定する
- **仕上げ**：Yomiyasu型の文章基準（主述・条件・因果の明確さ、簡潔さ）を適用する。外部Skillは必須ではありません

**確認事項**：読みやすいと推定できることと、実際の読者が理解したことは別です。理解度が重要なら、説明・予測・応用を用いた読者テストで確認します。

## 使い方

ChatGPTのSkillsに本リポジトリの `SKILL.md` を含むフォルダを追加するか、配布された `skill.zip` をインポートします。

たとえば、次のように依頼できます。

- 「Wakarimiで、この数学解説を高校生向けに構成し直して」
- 「この記事をレビューして、読者が理解できなくなる段落と理由を指摘して」
- 「SQLの `GROUP BY` を、実務未経験者に分かる順序で教えて」

## ファイル構成

- [`SKILL.md`](SKILL.md)：起動条件、八つの原則、設計・改稿・レビュー手順、検証項目
- [`references/examples.md`](references/examples.md)：数学・SQL・レビューの具体例
- [`agents/openai.yaml`](agents/openai.yaml)：表示名などのUIメタデータ

## 開発と配布

`SKILL.md` を正本として更新し、Skill Creatorのバリデータで確認した上でZIPを再生成してください。ZIPは `wakarimi/` をルートとする単一Skillです。
